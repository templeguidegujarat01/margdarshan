{%- comment -%} "Read more" button for a "Where these facts come from" section (section#sources). Place it right after the source list (ol.cite-list / ul.us-sources). With JS on, main.css (block "Sources fold") shows only the heading and the first 3 sources from the first paint; the intro, the other sources, the Markdown copy box and the "Spotted something out of date?" line sit behind this button. site.js (block "Sources fold") counts the hidden sources into the label and toggles .is-open on the section. No JS = everything shown, button hidden. With 3 sources or fewer, all sources stay visible and the button opens only the notes. {%- endcomment -%}
