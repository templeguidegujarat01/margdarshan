Used by in-career.html for a section part with `steps:` ({title, text}). Node kinds are read from the step title only, so a node is never labelled with something the data does not say. Words are matched as written (Liquid `contains` is case-sensitive): start first step whose title names a Class ("Class 12", "Class 11–12, PCB") exam title names an exam: "xam" (Exam/exam), "ntrance", CLAT, JEE, NEET, CUET, AIBE, NATA, NIFT, GATE, UPSC, or the WHOLE title is a professional-body exam level: Foundation, Intermediate, Final (CA, CMA), CSEET, Executive, Professional (CS), Applied Knowledge, Applied Skills, Strategic Professional (ACCA). Whole-title only, so "Foundation training & posting" (UPSC) and "Foundational certification" stay stages. Articleship, Practical Training and EPSM are training / an ethics module, not exams, so they stay stages as well. licence title names registration, membership or a licence: "egist", "Membership", "icen" — never the first step (ACCA "Register" = student sign-up) goal the last step, unless it is a single licence step (no " or ", no "consider") stage everything else (study, training, practice) — shown as "Step N", no kind badge Titles with "prep", "course" or "Part I" stay stages ("GATE prep", "Pre-registration course", FRM "Register Part I" = exam sign-up, not a gate or a licence). Every badge is visible text, so the colour is never the only signal.
