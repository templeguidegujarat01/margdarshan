{%- comment -%} Country edition switch — a property-style dropdown (like Google Search Console's property picker) at the top of the sidebar, so it is also the first thing in the mobile drawer. The button shows the current edition; the menu lists every edition in _data/regions.yml → list. Picking one opens that edition, whose pages carry its own sidebar (_data/regions.yml → .nav), so the nav tree switches with the page. Built on
/: opens and closes without JS; the options are plain links. scripts.html adds outside-click / Escape closing and arrow-key movement. Destination: the same-field page in the other edition only when a real mapping exists — a pathway in _data/us/pathways.yml marked `live: true` (its page is built) with an `in_page` — otherwise that edition's home. Never a guessed URL. Current edition: aria-current="true" + check mark + bold option (not colour alone).
