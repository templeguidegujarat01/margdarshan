# Legacy study-abroad files (archived 2026-10-29)

These files drove the old study-abroad country pages. The Study Abroad engine (`_data/in/abroad/*.yml`,
`_data/in/abroad_common.yml`, `_includes/abroad-*.html`, `scripts/build-abroad.mjs`) replaced them and nothing
on the site reads them any more. They are kept for reference only.

- `country-page.html` — old include (was `_includes/country-page.html`)
- `study_abroad.json`, `country_pages.json`, `country_portals.json`, `country_careers.json` — old data (were in `_data/`)

`_archive/` starts with an underscore, so Jekyll neither builds nor loads it, but git still keeps the files.
