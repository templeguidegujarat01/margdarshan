JOURNEY BLUEPRINT — ONE CAREER (Education Margdarshan, emargdarshan.com)

You are writing the data for ONE career page on an Indian student career website. The page is a "Journey Blueprint":
the NATIONAL road to one career, stage by stage — Class 8, 9, 10, 11, 12, in college, graduated, working / switching
career — with the real student doubts at each stage. A robot publishes your file automatically: it checks the
structure and opens every link, but it cannot check facts. Students will plan their lives on this page, so every fact
must come from an official document you actually opened. The REQUEST at the very bottom names the career.

Do not ask me questions. Do the whole job, then give the file.

════════ STEP 0 — Is this career already built? ════════
The REQUEST lists "already built" blueprint ids. Decide:
  • SAME ROAD as a built one (same entry qualification + same exam / licence / regulator, only a different job name,
    e.g. "Railway Station Master" when "railway-ntpc" exists) → do NOT write a page. Output FORMAT B (alias) only.
  • A specialisation with its own degree, exam, licence or recruiting body → it is a NEW road → FORMAT A.
  • If unsure, it is a new road → FORMAT A.

════════ STEP 1 — Research (turn web search ON) ════════
Facts may come ONLY from official sources:
  ministries and departments (.gov.in, .nic.in), recruitment and exam bodies (UPSC, SSC, RRB, IBPS, NTA, NBEMS, state-
  neutral central bodies), statutory councils and regulators (NMC, DCI, INC, PCI, BCI, COA, ICAI, ICSI, ICMAI, DGCA,
  DG Shipping, RCI, NCAHP, NCTE, UGC, AICTE, SEBI, IRDAI, IBBI …), skill bodies (NCVET, Skill India, sector skill
  councils, DGT), central universities / IITs / NITs / AIIMS / national institutes (.ac.in, .edu.in, .res.in), PSUs'
  own sites, the Gazette, India Code, PIB.
  Wikipedia, coaching sites, news sites, Shiksha, Careers360, Collegedunia, Jagran Josh, blogs = only to FIND the
  official file. Never cite them.
Rules:
  1. Use the newest notice / brochure / regulation (2026, 2025-26, or the latest one that is still in force). Open it.
  2. NEVER type a number, date, fee, age limit, percentage, seat count, pay level or salary that you did not read on
     the page you cite. Not found → leave it out (for pay write `pay_note` saying no official pay scale is published).
  3. Every `url` is the exact page or PDF you read, https only. Never build or guess a URL.
  4. NATIONAL / CENTRAL road only. No state-by-state rules, no state quotas, no state scholarship. If only states hire
     for this job, describe the national qualification road and write ONE line in `state_rules` saying each state
     recruits through its own commission / board.
  5. Simple English a Class 8 student understands. Short sentences. No "best", "top", "leading", "No. 1",
     "guaranteed", and no placeholder lines ("TBA", "will be updated", "launching later"). No coaching or college brand names. No HTML, no markdown inside text.
  6. If the career has NO official road at all (no degree, exam, licence or certificate named by any official body),
     still write FORMAT A using the closest official skill route (NCVET / NSQF qualification, Skill India, the
     relevant degree's regulator) — and say plainly in `core.routes` that no licence is required.
